# Grow

Grow is an early web development learning project created while learning HTML and CSS with guidance from a teacher.

This project was one of my first hands-on coding experiences, where I learned the fundamentals of building a webpage step by step alongside my teacher. It represents the beginning of my journey into web development.

## Tech Stack

- **HTML5:** Structuring webpage content
- **CSS3:** Styling and layout design

## Getting Started

### Prerequisites

- A modern web browser
- A code editor, such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/najlanafisah/Grow.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Grow
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Project Structure

```text
Grow/
├── asets/           # Project assets
├── coba/            # Practice files
├── index.html       # Main webpage
├── extra-class.html # Additional practice page
└── Mystyle.css      # Stylesheet
```
